# TeamAI Product Roadmap

**Generated:** 2026-05-13
**Project:** TeamAI v0.1.0 — Multi-Agent Claude Code Orchestrator

---

## Executive Summary

TeamAI is a v0.1.0 Next.js web application that orchestrates multi-agent Claude Code CLI workflows through a browser UI. The core pipeline engine (ProcessManager + Orchestrator) is functional with real-time WebSocket streaming, interactive terminals via xterm.js, multi-provider LLM support, and basic crash recovery. The Kanban board renders task cards with drag-and-drop phase transitions. 

However, the product is pre-production: it lacks authentication, a CI/CD pipeline, structured logging, and a database backend. The codebase has widespread silent error swallowing (~60 empty catch blocks) that will make production debugging difficult. Competitive analysis shows TeamAI's unique strengths are its multi-agent pipeline with role specialization and Kanban project management — features no direct competitor offers. The highest-impact investments are closing the production readiness gap (auth, logging, CI/CD) and adding MCP protocol support to match emerging ecosystem standards.

### Competitive Positioning

**Where TeamAI is uniquely strong:**
- **Multi-agent pipeline** — No competitor orchestrates specialized agents through defined phases
- **Project management UI** — Kanban board, roadmap, and task detail views are unique
- **Role specialization** — Planner, coder, QA reviewer, merger roles with distinct personas
- **Recovery** — Auto-detection of interrupted tasks and stale sessions

**Where competitors are ahead:**
- **IDE integration** — Cursor, Windsurf, and Cline integrate tightly into the developer's editor
- **Authentication** — IDE-based tools inherit editor auth; TeamAI has none
- **MCP protocol** — Cline and Cursor recently added MCP server support
- **Maturity** — Aider and Cursor have years of real-world usage and community

**Underserved gaps (TeamAI opportunity):**
- No competitor offers a headless, multi-agent pipeline with a project management UI
- No competitor supports role-specialized agents with configurable personas
- Git worktree isolation for parallel agents is unique
- The combination of interactive terminals + automated pipelines is novel
